REVISIÓN FORMATIVA
Se distingue descripción, hipótesis y valoración profesional. No se diagnostica la causa ni se certifica seguridad por el aspecto, ancho de una fisura, color o sonido. Se han revisado las comprobaciones para evitar tocar, empujar, golpear o retirar elementos dudosos. Se incorpora una pauta para registrar y comunicar observaciones.
La actividad se realiza con el docente y los procedimientos de la obra. Los criterios aplicables dependen del proyecto, sistema, producto y contexto. No incluye instrucciones de reparación ni autoriza a intervenir.
Referencias generales: CTE DB-SUA, CTE DB-SI e INSST Construcción, enlazadas en la app. Consulta documental: octubre de 2026.

PROGRESO
Solo se guardan en este navegador las fichas repasadas y ejercicios superados. No se envían respuestas ni se crean cuentas. Cambiar de dominio, navegador o dispositivo no traslada el progreso; borrar los datos del sitio lo elimina. Si el navegador bloquea el guardado, se informa en pantalla. «Reiniciar el progreso de ejercicios» pide confirmación y conserva las fichas repasadas. Repetir un ejercicio no borra un logro anterior.

PUBLICAR
Descomprime el ZIP. Conserva juntos index.html, data.js, app.js, ejercicios.js, .nojekyll y la carpeta img completa.
Cloudflare Pages o Netlify: carga la carpeta que contiene directamente index.html como sitio estático, sin comando de compilación. No subas una carpeta contenedora vacía ni solo el HTML.
GitHub Pages: sube los archivos descomprimidos al repositorio con index.html en la raíz. En Settings > Pages, elige Deploy from a branch, main y /(root). Guarda si hay cambios y espera a que el despliegue termine correctamente en Actions.
Las rutas de imágenes y scripts son relativas y las páginas usan #/; sirven también en una subcarpeta de GitHub Pages. No hay dependencias de servicios externos para mostrar el contenido o corregir ejercicios; solo las referencias abren webs externas.
Para probar sin publicar puedes abrir index.html con JavaScript activo. El guardado local puede variar al abrir archivos directamente; comprueba el sitio publicado para el uso normal.
